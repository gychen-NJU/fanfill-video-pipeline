# 工作台（Web 面板）：引导式流水线

> **它是什么**：一个可选的 DSH Web 面板，把这条流水线的七个阶段摆成"可点、可交、可派单"的操作台——
> 按阶段向你索要素材、给出逐步引导、把免费动作直接跑在本机（带实时日志），并把该由智能体做的阶段
> **一键派给当前会话**。安装见 [`INSTALL.md`](../INSTALL.md) §2，验证见 §3。
> **换首歌也能用**：引导内容来自数据文件（通用骨架 + 本歌覆盖），不是写死在代码里。

---

## 1. 三个页签组

| 区域 | 作用 |
|---|---|
| **引导**（默认） | 七个阶段的手风琴：每个阶段显示「目标 / 验收门槛 / 需要你提供什么 / 怎么做 / 产物 / 子步骤与验收」。当前阶段默认展开，异常项置顶 |
| **素材 / 歌词 / 出片 / 账本** | 素材齐缺（按流水线角色）、LRC 名义时间 vs 实测起音逐句对照、分镜表（含按单价估算金额）、逐笔花费与预算执行条 |
| **日志** | 本轮在本机跑过的动作与实时输出（可中止） |
| **底部 dock** | 和**当前会话**的智能体说话；三个快捷提示词：下一步的提示词 / 解释这一步 / 我在哪一步 |

## 2. 每个阶段向你什么、能一键做什么

| # | 阶段 | 你要交的 | 工作台能直接跑 | 谁做主体 |
|---|---|---|---|---|
| 1 | 素材盘点与配置 | 原曲音频、翻填词 LRC（必填）；原词 LRC、原版 MIDI、CG/参考图、音色素材（可选）；基本信息表单 | 配置自检、环境探活（进程内，不写文件） | 工作台 |
| 2 | 分离 / 扒谱 / 出人声 / 混音 | 分离人声、伴奏、人声渲染、母版（若你自己做过） | 由**本歌覆盖文件**声明（各歌工具链不同） | 智能体 |
| 3 | 歌词对齐与分镜 | — | 分镜预览 `--plan`、prompt 自检、分镜真跑、参考图真出 | 智能体 |
| 4 | 出片（**唯一花钱**） | 参考图、每段 prompt | 只跑 `--plan` 报价；**永不替你花钱** | 只能派单 |
| 5 | 字幕与合成 | — | 字幕预览/真出、合成预览 | 智能体 |
| 6 | 超分与核验 | — | 超分预览、核验预览 | 智能体 |
| 7 | 封面与投稿文案 | — | 封面预览/真出 | 智能体 |

阶段状态**由文件派生**（产物在不在、配置键填没填、素材齐不齐），不需要手填；标了"待你勾选/确认"的子步骤
（如"换音色 SVC 可选"）在面板上给一个真勾选框，写进 `_进度/工作台状态.json`（工作台自己的状态文件，
不碰 `_进度/进度.md`）。

## 3. 交素材的三种方式

1. **上传**：落到该槽约定的目录（如原曲 → `01_input/原曲.<ext>`），并**自动回写**项目配置里对应的键；
2. **传文件夹**（多文件槽）：目录内容（含子目录）进目标目录，文件名保留；
3. **选已有**：文件已在工作区里 → 只把**路径**写进配置，**不动文件**。

写回纪律（宿主侧强制）：**绝不覆盖**（同名加 `-2`）、改配置**先备份**、`sha256/mtime` **乐观锁**（别处改过 → 409）。

## 4. 新建一首歌（换歌入口）

面板顶部「＋新建翻填任务」→ 选父目录 + 填歌名等 → 建立。会建出：目录骨架、通用 PV 脚本（`scripts/80–87` +
`lib/`）、技能目录、`翻填项目.json`、`_进度/进度.md`、以及一份空的 `工作台流水线.json`。
**不会**复制素材、不会复制音乐线脚本（那些是歌专用）、目标目录非空会被拒。

## 5. 自定义引导内容

- **通用骨架**：`ui-workbench/pipeline.default.json`（七阶段、素材槽、动作、检查器）。换歌**不要**改它。
- **本歌覆盖**：`<歌曲工作区>/工作台流水线.json`（字段白名单：`slots`/`actions`/`form`/`notes`/`steps`/`artifacts` +
  若干标量；未知字段会报错而不是静默丢弃）。模板见 [`song-pipeline.example.json`](../ui-workbench/song-pipeline.example.json)。

最小例子（给某阶段加一条只读动作）：

```jsonc
{ "schema": 1, "song": "<歌名>",
  "stages": { "s2": { "actions": [ {
    "id": "music.loudness", "label": "响度 / 真峰值校验（只打印）",
    "kind": "preview",                       // preview 只读｜local 写产物（需确认）｜paid 花钱（永不本机执行）
    "interpreter": "powershell",
    "argv": ["-NoProfile","-ExecutionPolicy","Bypass","-File","scripts/90_loudness_check.ps1",
             "-InFile","{{config.audio.master}}"],
    "requires": [{ "kind": "file", "path": "{{config.audio.master}}" }],
    "writes": false, "costCny": 0, "timeoutMs": 300000 } ] } } }
```

占位符：`argv` 里解析成**绝对路径**，`requires/outputs/artifacts` 里解析成**歌根相对路径**；
检查器只有五种：`configKey` / `file` / `glob` / `manual` / `allOf` / `anyOf`。
改完覆盖文件**刷新页面即生效**。

## 6. 权限与信任模型（装机前请读一遍）

宿主半边挂的是 DSH 那条**没有平台鉴权**的 prefix 路由，所以安全是自己扛的：

- **变更类请求**要自定义头 `x-fantian: 1` + POST；响应不发 CORS、不实现 OPTIONS；只读端点只认 GET/HEAD。
- **所有路径**先拒绝对路径/盘符/UNC/`..`，再解析**真实落点**（`realpathSync.native`）确认仍在歌曲工作区内——
  工作区里放指向外面的 junction/symlink 也会被挡。
- **`song=` 只认已登记的歌**；向导选择父目录限定在 `browseRoots`（默认＝已登记歌曲的父目录）。
- **付费动作宿主侧直接拒**（403）：`kind: paid` 或 `costCny > 0` 永不执行，只能派单给智能体（提示词里会要求先报价）。
- **`<歌曲工作区>/工作台流水线.json` 等于可执行内容**：来自它的动作一律标 `untrusted`、**每次都要二次确认**；
  解释器要么是不带路径的命令名，要么在工作区内，要么写进插件配置 `allowedInterpreters`；`argv` 不许有越界路径。
  **别把别人给的工作区目录连同这个文件一起信任。**
- 写入一律**非覆盖**；上传超限**先回 413 再断流**（你能看到原因）；作业并发上限 4，取消后 5 秒强制结算。

## 7. 生效方式与排障

| 改什么 | 怎么生效 |
|---|---|
| 宿主半边（`index.js`、`lib/*.mjs`）、profile 补丁 | **重启 `dsh web`**（实测：JS 源码不会热重载） |
| 客户端半边（`client.js`）、本歌覆盖文件 | **刷新页面** |
| 歌注册表 | 运行时文件 `songs.json`（默认在插件目录旁，可用 `registryPath` 改址） |

常见状态码：`409` 配置被别处改过（乐观锁）｜`403` 付费动作 / 未确认的写动作 / 未受信的覆盖动作｜
`413` 超过上传上限｜`405` 只读端点被别的 HTTP 方法打了｜`429` 并发作业已满。

## 8. 验过什么、没验什么

- ✅ 宿主半边 **118** 条无头断言（上传/穿越/乐观锁/付费拒绝/作业树杀/并发上限/v1 契约回归 + 对抗性回归）；
- ✅ 客户端半边 **30** 条无头渲染断言（六个页签、派单真进会话、未受信动作强制确认）；
- ✅ 仓库自带 `tools/smoke-test.mjs` **13/13**（v1 快照契约一字未改）；
- ✅ 独立对抗性核验（2 高危 + 4 中危 + 10 低危）已全部修复并钉成回归断言；
- ✅ v2 客户端半边在真实浏览器里渲染过：`console.error = 0`，宿主仍是旧版时能优雅降级；
- ❌ **v2 在真实浏览器里的完整点击路径**（上传/派单/向导）与**亮/暗主题**未实测；
- ❌ >50 MB 的大文件上传未实测（512 MB 上限是代码约定）。

> 关于主题：面板样式只用主题 token，所以逻辑上跟随宿主；但参考实现所在的那台机器上外观由皮肤插件接管
> （`data-ds-theme-source=dark`），设置里的浅色/深色方块点了不生效，因此**没有实测过亮色**。
